### 1. [Customer Churn Analysis](https://github.com/junskii/customer-churn-analysis)
**Python · Pandas · Statistical Analysis · Customer Segmentation · Tableau**  
A customer churn analysis project using the IBM Telco dataset to identify customer groups with higher historical churn and inform retention priorities.  
The project combines data cleaning, feature engineering, exploratory analysis, statistical testing, and rule-based customer segmentation in Python, with interactive Tableau dashboards presenting churn patterns and priority-segment profiles.

### 2. [E-Commerce Sales Analytics — Olist](https://github.com/junskii/olist-ecommerce-sales-analytics)
**MySQL · SQL · Data Analysis · Tableau · E-Commerce Analytics**  
An e-commerce sales analysis project using the Brazilian Olist dataset to explore sales trends, product-category and customer-state contributions, repeat purchases, and the relationship between delivery delays and customer reviews.  
The project uses MySQL for data preparation, data-quality checks, and business analysis, with an interactive Tableau dashboard presenting GMV, order volume, average order value, and delivery-related review patterns.

### 3. [AmanKU](https://github.com/junskii/AmanKU)
**SwiftUI · Supabase · VisionKit · MVVM · AI Summary · Web Admin**  
A cross-platform security-post management system for an Islamic boarding school (pesantren). The iOS app adapts by device — officers on iPhone manage package intake (OCR + barcode scanning), visitor check-in/out, and incident logging across four tabs, while an iPad kiosk provides self-service package pickup for students. Includes an AI-powered daily summary via a Supabase Edge Function that calls the OpenAI API, rendered with a custom SwiftUI Markdown theme. A static HTML/JS admin panel covers dashboard, officer management, and read views. Built with SwiftUI (MVVM), supabase-swift, VisionKit, and a dark glass UI theme with custom design tokens.

### 4. [Hospital Patient Management System](https://github.com/junskii/pythonfundamental)
**Python · CRUD Operations · Data Management · Hospital System**  
A comprehensive command-line application for managing hospital patient records with full CRUD functionality.  
The project implements robust data validation, input standardization, and provides an intuitive menu-driven interface for healthcare data management using Python fundamentals, dictionary operations, and user input handling.

### 5. [Supermarket Customer Analysis](https://github.com/junskii/SupermarketCustomerAnalysis)
**Python · Data Analysis · Business Intelligence · Customer Segmentation**  
A comprehensive data analysis project for identifying customer characteristics that predict marketing campaign response.  
The project implements robust data cleaning, feature engineering, exploratory data analysis (EDA), and inferential statistics using Python fundamentals, pandas operations, statistical testing (t-test, chi-square), and data visualization to provide actionable business insights for improving marketing campaign effectiveness.

### 6. [Pharmacy Management System](https://github.com/junskii/PharmacyManagement)
**Software Design Patterns · Spring Boot · Java · Web Application**  
A comprehensive pharmacy management system built as a learning project to demonstrate the practical implementation of 6 design patterns (Factory, Observer, Command, Decorator, Strategy, Template Method). The application provides complete features for managing medicines, processing sales transactions, user management with role-based access control, and generating reports using Spring Boot, MyBatis, and Thymeleaf.
